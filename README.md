# FASTMEAN Russian UI

Отдельный установщик русского запуска **FASTMEAN 6.1 / 6.0** для Windows.
Помощник задаёт русскую кодировку внутри запускаемой FASTMEAN, сохраняя
системные настройки Windows. Он предназначен для старого ANSI-интерфейса,
в котором русский текст и ввод могут отображаться неверно.

Этот проект независим от FASTMEAN MCP. Для установки готового помощника
Python, Codex и MCP не нужны. Сама FASTMEAN устанавливается отдельно по своей
лицензии; её файлы, решатели, шрифты и руководство сюда не входят.

## Установка

[**Скачать установщик EXE**](https://github.com/maxewka/fastmean-russian-ui/releases/latest/download/FASTMEAN-RussianUI-Setup.exe) · [Исходники и контрольные суммы](https://github.com/maxewka/fastmean-russian-ui/releases/latest)

1. В разделе **Releases** этого репозитория скачайте
   **`FASTMEAN-RussianUI-Setup.exe`**.
2. Запустите файл обычным способом. Установщик найдёт существующую FASTMEAN
   и разместит помощник в отдельной папке пользователя.
3. После завершения используйте созданный ярлык русского запуска. Перед
   переходом из ранее открытой FASTMEAN сохраните свои изменения.

Поддерживаются Windows 10/11 с .NET Framework 4.8. Нативная программа
и её текущие схемы сохраняются. Установщик не переключает системный язык,
не устанавливает шрифты и не меняет ассоциации `.scm`.

Если Windows блокирует EXE или DLL из-за подписи либо политики запуска,
остановитесь и используйте разрешённый владельцем компьютера способ установки.
Помощник не отключает защиту и не запрашивает повышение прав для её обхода.

## Открытие схем

Запускатель поддерживает пустой запуск, явный путь к FASTMEAN и один путь к
схеме, который передаёт Windows через **«Открыть с помощью»**:

```text
FastmeanRuRunner.exe
FastmeanRuRunner.exe "C:\Circuits\фильтр 20 Ом.scm"
FastmeanRuRunner.exe "C:\Apps\FASTMEAN\Fastmean.exe" "C:\Circuits\example.scm"
```

При выборе приложения для `.scm` указывайте новый установленный
`FastmeanRuRunner.exe`. Старые версии помощника могли принимать путь схемы
за путь программы и выдавать `Target executable was not found`.

В поле номинала резистора **20 Ом** задаётся числом `20`, а **20 кОм** —
значением `20k` с латинской `k`. Единицу «Ом» дописывать не требуется.

## Проверка и удаление

`FastmeanRuRunner.exe --check "C:\Circuits\example.scm"` проверяет пути и
наличие runtime-файлов, печатает JSON и не запускает FASTMEAN/Locale Emulator.
Такая проверка не подтверждает визуальное отображение или ввод кириллицы.

Установщик также предоставляет диагностический `--check` и управляемые
режимы установки/удаления. Подробности — в [технической инструкции](docs/README.md).
При удалении помощника FASTMEAN и схемы пользователя сохраняются.

## Сборка из исходников

Готовый установщик предназначен для пользователей Windows. Разработчикам
нужны существующий Python 3.12+ и x86-компилятор C# из .NET Framework 4.x:

```text
python -m unittest discover -s tests -v
python build.py --output dist --version 1.0.0
```

Сборка получает только проверенный открытый runtime Locale Emulator из
официального выпуска. Результаты, контрольные суммы и комплект исходников
создаются в `dist`; они не добавляются в Git.
